🎓 Student Grade Tracker

✨ Features

Feature| Description
👨‍🎓 Student Details| Add student ID and name
📝 Marks| Enter marks for different subjects
➕ Total| Calculate total marks
📊 Average| Calculate average marks
🔼 Maximum| Find highest marks
🔽 Minimum| Find lowest marks
🏆 Grade| Automatically calculate grade
📋 Report| Display complete student performance

---

- ☕ Java
- 🐍 Python
